# Architecture decisions

No standalone ADRs are established in this scaffold. Verified phase decisions
are maintained in [`backend/docs/phase-0-decisions.md`](../../backend/docs/phase-0-decisions.md)
and current authorization decisions in [`backend/docs/rbac.md`](../../backend/docs/rbac.md).
Do not treat the template as a project decision.

For a verified or newly made decision use ADR-0001-title.md with Context, Decision, Alternatives, Consequences and Status.
